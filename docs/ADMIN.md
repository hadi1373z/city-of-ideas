# Administration directory

`/city-of-ideas/admin/` is the common entry point for the three existing sections:

- Art collection: `../art-exhibition/`, the public illustrated archive.
- Papers: the existing private mathematical paper library Site, project
  `appgprj_6b0126857af48191a850927d76978854`.
- Comments: `/inbox` on the existing guestbook Site, project
  `appgprj_6afe0785a2d08191949699269510429c`.

The city header's Admin link is also transported into the small-screen controls
menu. The directory works without a 3D context; links work without JavaScript.
FA/EN/DE text reuses the existing language preference. The directory contains no
private records, database access, credentials or new authentication system.
Papers and comments retain their existing server-side access checks. The art
archive remains a public viewing catalogue; this change adds no art editor and
does not claim that changing paper metadata publishes it automatically to the city.
