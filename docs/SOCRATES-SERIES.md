# Socrates as the city host

The current character is an original warm illustrated interpretation: a bald crown, silver curls and beard, attentive eyes, linen robe and teal himation. A shared procedural model keeps the resident, travelling visitor and rehearsal host visually consistent. It has separate walking, speaking and idle poses and respects reduced motion. The original source visitor factory is retained intact for source comparison.

Choose **Walk with Socrates** from the welcome screen. The episode rehearsal panel contains seven English/Persian/German draft episodes: the city plaza, Socrates’ home, philosophers’ homes, artists, the object market, mathematics and Ideas Park. Each has three caption beats, an explicit destination button, play/pause, manual advance, a host framing control and a cinema view. Escape or the visible exit button restores the normal controls. Closing the panel restores the normal resident.

The host follows on unobstructed same-level routes while narration is paused. A blocked stage location reports that more room is needed. Long-distance travel requires choosing a stop or calling Socrates nearby; the actor is hidden across disconnected levels rather than walking through walls. Stage movement is checked with the same city collision function and bounded source path planner. The host pauses his walk during narration and faces the visitor.

Narration is original fictional writing for the future video series, not a historical quotation or a generated historical answer. Optional read-aloud uses the browser’s available speech voices; unavailable language voices or playback failure are reported, and captions remain usable. Captions work without speech support. Rehearsal does not create a video file, a recorded performance or a custom production voice.

Portrait reference for the recognisable Socratic forehead, nose and beard: [The Metropolitan Museum of Art, Prisons Real and Imagined](https://www.metmuseum.org/pt/perspectives/articles/2022/3/jacques-louis-david-death-of-socrates). The city character and its geometry are original, not a museum asset.

The actual video project can build on these consistent episode IDs, scripts, character and locations. Recording, final scripts, voice casting, camera choreography and editing remain production work for that project.
