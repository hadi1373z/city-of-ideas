# Book and interface languages

English remains the complete Thomas Common text from Project Gutenberg [#1998](https://www.gutenberg.org/ebooks/1998), with its original chapter IDs and paragraphs unchanged. German is Nietzsche's original from [#7205](https://www.gutenberg.org/ebooks/7205), preserving historical spelling. Both editions contain all 81 chapters; their paragraph divisions differ. The comparison reader keeps the same chapter, without implying sentence alignment.

Persian contains all 3,466 English source paragraphs across 81 chapters. It is a **machine translation draft**, generated locally with Argos Translate English–Persian 1.5 / OpenNMT. Selected passages were compared with a local NLLB-200 distilled 600M translation and with the German original. All 81 titles and 39 opening/Three Metamorphoses paragraphs received original editorial Persian renderings; recurring philosophical terms received a glossary review. The remaining text has not received complete human literary editing. Read it beside German or English using the reader's comparison selector. No modern copyrighted Persian edition was copied.

The public German interface dictionary was generated locally with Argos Translate English–German 1.3, with manually reviewed navigation labels. Names, formulas, identifiers, user input, private notes and source quotations are outside public-interface translation. Some imported articles retain their original language when no reviewed public translation is available. A language switch does not translate or upload private writing.

Argos packages came from the [official package index](https://github.com/argosopentech/argospm-index). Their model documentation credits OpenNMT, OPUS and the constituent corpora, including MIZAN for Persian. Models and intermediate caches are not shipped with the website. NLLB comparison model: `JustFrederik/nllb-200-distilled-600M-ct2-int8`, revision `302d78f00e6fdb50a1064059df7c392b735e9d05`; see the original NLLB model's research-use licensing. The website serves precomputed text; no translation API key or paid inference is required.

The glossary distinguishes Übermensch (ابرانسان), Untergang (context-dependent فروشدن / فرود / غروب), Selbstüberwindung (خودچیرگی), ewige Wiederkunft (بازگشت جاودان), Wille zur Macht (خواست قدرت), and letzter Mensch (واپسین‌انسان). These choices aid comparison and do not claim to settle interpretive questions.
