The source Home backend deliberately reports its original hosted GPT and ChatGPT routes as disabled. Guided Socrates is the actual original local dialogue engine, with authenticated persistence; it is not a newly enabled language-model API. No provider key is embedded or required.

Private migration must use the original signed-in export and validated additive import. Runtime QA data is stored outside this project and excluded from every snapshot. Static assets never contain private archives, user credentials, identity headers or backend tokens.
