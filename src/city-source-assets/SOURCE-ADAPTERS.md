# Genuine city source adapters

House of Ideas commit: 48ccb361e8e64857f4e9f94f4598d8dc97970e00. Original artist catalogue: hadi1373z/artist-galleries commit 7161f1c420328386046ef6413c04a51868be38de. Atlas complete book source: 84f9f1d141e1a4dda4caa04d26476e958af42c19.

Load assets/three.min.js (r160), city-sources.js, city-book.js as classic scripts. No module build, second renderer, API credential, remote automatic asset request, or private saved state is used.

## APIs

- CITY_SOURCES.ARTISTS: original 10 artists, six genuine paintings each; all original attribution fields retained. CITY_SOURCES.buildArtCity(THREE, CITY_SOURCES.ARTISTS, options) returns the original group, houses, colliders, bounds, targets, canStand, insideAt, entryFor and dispose. The optional artist array can be omitted by passing options as the second argument.
- CITY_SOURCES.createSocratesStarter(): fresh canonical public six-room starter, seven doorway connections, zero private ideas. SOCRATES_STARTER is its source data. Shared grid/world helpers are exposed. furnishRoom(THREE, room, house, true) returns the genuine domestic furniture Group; buildInterior(house, room, THREE, {walk:true}) also returns obstacles and interactions. Furniture metadata has homeAction/bookId; BOOKS are original educational readings, not historical Socrates quotations.
- CITY_SOURCES.OBJECTS/STORE_OBJECTS: all 104 genuine catalogue entries; GLB_OBJECTS: 36 actual bundled models. Per-object source, creator, license, title, description, category, local source record and verified original-byte SHA256 remain available.
- CITY_SOURCES.loadObject(assetId or catalogue id, options) is a Promise returning an actual THREE.Group. By default it centers x/z, puts the base at y=0, and normalizes the longest dimension to 1. Use {normalize:false} for source dimensions. group.size, group.dispose(), group.userData.source and group.userData.animations are available. No placeholder model is substituted.
- CITY_SOURCES.loadPreview(item, options) returns Promise<{group,size,dispose}>. All 104 preview types are supported: actual GLBs, actual painting images, and genuine public learning-furniture/idea constructions extracted from residence-scene-v1.js.
- CITY_SOURCES.buildObjectMarket(THREE, {previewLimit:6, ...options}) returns the original physical open-air market group, bounds, spawn, guideAnchor, colliders, stalls, canStand, insideAt, entryFor, update, suspend, dispose. Call update({x,z}) using MARKET LOCAL coordinates while nearby: it loads the nearest six displays within 15 units, at most two concurrently, and releases others. previewLimit clamps 1–10. Call suspend() when leaving the market. previewStatus() returns readiness/pending/error state. All 104 source plaques/catalogue entries remain inspectable. The final aisle sign says City Avenue and has city-avenue action, allowing the owner to connect physical streets.
- Translate/rotate world points to each district’s local coordinate system before canStand/insideAt/update/entryFor; metadata and collision coordinates remain original local metres. The owner provides shared city ground, walkable connectors, home architecture, and controls.
- All texture/model loaders call options.assetUrl(path), then CITY_EMBEDDED_ASSETS[path] (also accepting keys without ./), then bundled relative paths. Registry values can be data URLs or blob URLs. Load via a local server for the ZIP; use the embedded registry for standalone HTML. No cross-origin automatic source requests are accepted. resolve paths such as ./city-source-assets/art-city/artworks/monet_water-lilies.webp and ./city-source-assets/object-store/assets/<sha256>.glb.
- All 10 original project song WAVs are bundled locally, with actual playback controls supplied by CITY_OBJECT_TOOLS. Music items have audioAvailable:true, audioUrl, originalAudioUrl, hasOriginalAudio and preserved source provenance.
- CITY_BOOK={title,author,translator,source,license,language,parts:[23,22,16,20],chapters:[{id,title,part,paragraphs}]}; paragraphs exactly copy Atlas fullBlocks, preserving full public-domain Thomas Common English book text. Part 1 includes prologue plus 22 discourses. 81 sections total.

## Rights and preservation

All catalogue-specific attribution is in city-sources.js. GLBs retain actual source bytes; 36 hash checks passed, all are self-contained GLB v2, no external resources or extra compression decoders required. Model labels include CC0 1.0, project-created model, original project composition/poster, and original project geometry. Painting attribution/rights and per-file reproduction links remain intact. Project source labels are preserved rather than replaced with a fabricated blanket license. House public template is not an archival migration of private owner state, conversations or notes.

Official GLTFLoader/toTrianglesDrawMode are pinned to Three.js r160, adapted from ES modules to the existing global THREE; MIT license included. Upstream: https://github.com/mrdoob/three.js/tree/r160/examples/jsm. Raw originals retained under vendor for review; only toTrianglesDrawMode is included in the runtime adapter.

Assets copied: 60 paintings (21472498 bytes), 36 GLBs (50058840 bytes), their available genuine source records, and pinned loader provenance/license. All 10 original project song WAVs are included (10,749,890 bytes); see audio-audit.json.
