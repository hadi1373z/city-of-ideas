# Approved cloister reference

`hexagonal-cloister-approved.png` is the concept image supplied and approved by
the user on20November2026. It guides the main-city Escher museum: a hexagonal
vaulted court, two-storey arcades, Perspective/Tessellation/Topology wings, a
lower cloister, real surface stair and connection to the undercity circuit.

Keep this design reference separate from credited Escher prints in the runtime
gallery. It is not installed as a city artwork or presented as a historical
Escher architectural drawing. The implemented footprint and navigation authority
are `src/escher-cloister-layout.js`; the established surface descent remains
`src/escher-descent-model.js`. See `docs/ESCHER-DEPTH.md` for implementation and
proportional limits.
